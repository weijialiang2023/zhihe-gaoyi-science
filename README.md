# 知核 · 高一同步问答

- 题库共 1800 道不重复题目；化学 783 道、生物 655 道。
- 190 道公开考试真题、150 道独立精编或真题改编，41 道多项选择题。
- 化学覆盖必修第一册全册，生物覆盖必修1《分子与细胞》全册。
- 三档难度：高难、超难、极难。
- 选择题四选项均有详细解析和错误订正，重点题附结构示意图。
- 完成训练或答过题后中途退出，都会保存练习记录。
- 章节训练支持“真题优先 / 仅公开真题 / 全部题源”和单选、多选筛选。
- 选中文字后默认使用离线本地精讲；也可切换免密 AI 或 DeepSeek，失败会自动回退。

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。

## 构建

```bash
pnpm build
```

构建产物位于 `dist/`。当前导出的静态版本已使用相对资源路径，可直接打开 `index.html`。
